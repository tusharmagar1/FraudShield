# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/tusharmagar1/FraudShield.git
cd FraudShield
```

## Create Virtual Environment

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

## Install

```bash
pip install -r requirements.txt
```

## Run

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
